# 🛒 বাজার দর (BazarDor)

প্রয়োজনীয় পণ্যের দাম এক নজরে দেখার জন্য একটি রেসপন্সিভ ওয়েব অ্যাপ।

## 🛠️ Technologies Used
- Next.js 15 (App Router) + TypeScript
- Tailwind CSS + DaisyUI
- BetterAuth (Email/Password, Google, GitHub)
- react-hot-toast
- Vercel deployment

## ✨ Key Features
1. ডায়নামিক হোম পেজ — Top 6 risers, Top 6 fallers + সব পণ্য গ্রিড
2. প্রোডাক্ট ডিটেইলস পেজ (Protected) — Min/Max/Avg + বাজারভিত্তিক টেবিল
3. ক্যাটাগরি পেজ — সর্টিং (ডিফল্ট / কম / বেশি), skeleton loader, empty state
4. BetterAuth — Email/Password + Google + GitHub, toast notifications
5. বাংলা সংখ্যা ও তারিখ — সব দাম বাংলা ডিজিটে, live price ticker
